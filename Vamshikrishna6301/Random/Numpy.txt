Low-Level Design (LLD) - Instagram Reel Trend Engagement Analysis
Difficulty Level: Medium
 Technology: NumPy
 Total Marks: 20
 Standards Followed: 6 Functions | 5 Visible Test Cases | 3 Hidden Test Cases
Problem Statement
A social media analytics team tracks Instagram Reel engagement trends for creators. Each value in a NumPy array represents the number of views received by a reel on a specific day.
Your task is to build NumPy-based functions that can:
Create a views array
Validate the views array
Compute engagement metrics
Categorize trend levels
Find the longest growth streak
Format view counts for reports
All functions must use NumPy arrays as input/output wherever applicable.
Function Rules
NumPy questions are function-based.
Do not create a class.
Implement all functions at module level.
Use exact function names and parameters.
Return NumPy arrays where the expected output is array-based.
Do not use Pandas.
Concepts Tested
NumPy array creation
Array validation
Numeric aggregation
Conditional labeling
Trend/growth analysis
Formatting numeric values

2. Validate Views Array
Checks whether the views array contains valid non-negative numeric values.
Function Prototype:
def validate_views_array(views_array: np.ndarray) -> bool:
Example Input:
validate_views_array(np.array([1200, 3500, -1800, 5200]))

False
Implementation Flow:
Check that the array is not empty.
Check that the array data type is numeric using np.issubdtype.
Check that all values are greater than or equal to 0.
Return True if all conditions pass, otherwise return False.

(total_views, average_views, maximum_views)
4. Categorize Trend Levels
Labels each day’s reel views as "Low Trend", "Moderate Trend", or "Viral Trend".
Function Prototype:
def categorize_trend_levels(views_array: np.ndarray) -> np.ndarray:
Example Input:
categorize_trend_levels(np.array([1200, 3500, 1800, 5200, 7600]))
Expected Output:
np.array(["Low Trend", "Moderate Trend", "Low Trend", "Viral Trend", "Viral Trend"])
Implementation Flow:
Apply the following trend rules:
Views < 3000 → "Low Trend"
Views 3000 to 4999 → "Moderate Trend"
Views >= 5000 → "Viral Trend"
Return a NumPy array of trend labels.
5. Find Longest Growth Streak
Finds the longest sequence of consecutive days where views increased compared to the previous day.
Function Prototype:

Example Input:

Implementation Flow:
Compare each day’s views with the previous day’s views.
Track consecutive increases.
