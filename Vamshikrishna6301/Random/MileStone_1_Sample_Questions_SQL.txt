SQL MEDIUM: Highest-Revenue Doctor per Department
Problem Statement
A hospital administration system tracks appointments and billing for doctors across multiple departments.
Each doctor belongs to a specific department, and each completed appointment generates a bill recorded in the Bills table.
You are asked to generate a report that shows the top-earning doctors within each department, based on the total billed amount from all their appointments.
For every doctor, compute:
The department name
The doctor name
The total revenue generated (sum of all their bill amounts)
The rank of that doctor within the department (highest revenue = rank 1)
Use RANK() (not ROW_NUMBER), so that if two doctors have the same total revenue, they receive the same rank.

Required output columns
department_name
doctor_name
total_revenue
revenue_rank

SQL Medium: Students Ranked by Course Enrollments
Database Description
The University Core database is designed to manage and organize essential academic information within a university setting. It maintains comprehensive records of departments, students, courses, and enrollments. The system facilitates the tracking of student-course registrations, departmental offerings, and the grading history of students, ensuring efficient academic administration and reporting.

Problem Statement
Write a query to assign a RANK and a DENSE_RANK to each student based on the number of courses they are enrolled in (in descending order). If multiple students are enrolled in the same number of courses, they should receive the same rank.
Return the output with the following columns:
student_id
name
course_count (total number of enrollments per student)
rank_by_enrollments (using RANK())
dense_rank_by_enrollments (using DENSE_RANK())
Order the final result by rank_by_enrollments.
